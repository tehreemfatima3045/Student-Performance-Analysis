# Student Performance Analysis

## Project Overview
This project analyzes student performance data using Python and explores grade prediction.

## Project Files
- `student_data.csv` — Original dataset.
- `predicted-results.csv` — Prediction results.
- `student data analysis.py` — Data analysis and visualization code.
- `prediction grade.py` — Grade prediction code.
- `graphs/` — Graphs and heatmaps saved as PNG images.

## Libraries Used
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn 

## Objectives
- Analyze student performance data.
- Visualize patterns using graphs and heatmaps.
- Predict student grades using a machine learning models.
